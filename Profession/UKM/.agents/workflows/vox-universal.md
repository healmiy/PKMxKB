Before generating image prompts, analyze the entire batch of sentences to identify recurring themes and objects.

CRITICAL IDEMPOTENCY RULE:
To ensure perfect visual consistency across the generated images, you MUST establish a "Design System" before writing the prompts:
1. **Unified Palette:** Define a single, strict color palette for the entire batch (e.g., "navy blue, gold, cream, and charcoal palette"). Do not change the palette per sentence. Apply this identical string to every single prompt.
2. **Strict Object Anchors:** Identify recurring objects across the sentences (e.g., a constitution book, a refugee silhouette, a scale). Define a hyper-specific, locked descriptor for each (e.g., "a heavy navy-blue constitution book with gold foil detailing"). Use this exact identical string every time the object appears in any prompt.

Once the Design System is established, convert every sentence into one complete papercut image prompt. Output them as a clean numbered list, one prompt per line, nothing between them, ready to paste in bulk. Each prompt must be fully self-contained and describe: one hero object (using your Strict Object Anchors), a maximum of three supporting objects, a background that matches that specific sentence, your Unified Palette, soft directional lighting with deep shadow gaps between layers, and generous negative space. Every object must be built entirely from thick cardstock, kraft paper, and construction paper, with dozens of individually cut layers, visible paper thickness, exposed cut edges, and handcrafted glue joints. Never show a canvas, board, table, or frame — the entire world itself is made of paper. End every prompt with: premium handcrafted stop-motion paper aesthetic, ultra-detailed, 8K, no text, no logos, no watermark.
